Quick status

This dashboard counts anonymous visitors using a browser-generated ID. “Online” is based on a 60-second heartbeat. It is not the same as Google/Adsterra official reporting.

Adsterra / Ad code

Paste only code you received from your own ad network account. Do not put ad code inside upload/download buttons. Never reward users for ad clicks.

Tool manager

The current build has 10 working client-side tools. This manager controls featured/popular flags in Firebase; it does not replace the tool code.

Security

Use Firebase Authentication for admin. Do not use “test mode” permanently; Firebase warns that test mode can make data publicly readable/writable. Add the included firebase-rules.json rules before public launch.
